## What is Vulpix?

Vulpix is a unified hub for navigating the fast-moving AI model landscape. Instead of jumping between a dozen scattered pages to figure out which model to use, Vulpix brings **models, datasets, benchmarks, and hands-on testing** into one clean interface.

## Core Features

### 🧠 Models Hub
Browse and inspect metadata for AI models from across the open ecosystem — architecture, size, license, and release details, all searchable and filterable in one place.

### 📚 Dataset Hub
Explore datasets the same way: structured, searchable, and easy to compare, so you know what a model was trained or evaluated on before you commit to it.

### 🏟️ Benchmark Arena
Put models head-to-head. Compare performance across standardized benchmarks and community activity to see how models actually stack up — not just on paper.

### 🎮 Playground (BYOK)
Bring your own API key and chat with models directly inside Vulpix. No setup friction — just plug in a key and start testing.

## Why Vulpix?

- **One place, not ten tabs** — models, datasets, and benchmarks live together instead of being scattered across the web.
- **Live, not stale** — metadata is synced on a schedule so what you see reflects the current state of the ecosystem.
- **Built as a real PWA** — installable, fast, and works the way a modern web app should.
